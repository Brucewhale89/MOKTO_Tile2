# T03 — BEST 커버플로우 (BEST 1~7, 스냅 인터랙션)

## 1. 목표
- 홈 상단 BEST 1~7을 앨범 커버플로우 형식으로 교체, 스냅 + 정지 후 상세보기 오버레이 포함

## 2. Step-by-step
1. 기존 rank badge 섹션 제거
2. 커버플로우 컨테이너: 중앙 카드 최대 크기·선명, 좌우 각 최대 3장까지 순차적으로 작아지고 기울어짐 (perspective transform)
3. CSS scroll-snap 또는 JS 기반 스냅: 스와이프 종료 시 가장 가까운 카드로 자동 정렬
4. 스냅 진행 중(정렬 애니메이션 중)에는 카드 위 모델명/상세보기 오버레이 `opacity: 0`
5. 스냅 완료(transitionend) 시 중앙 카드에 "상세보기" 오버레이 페이드인
6. 상세보기 버튼 또는 이미지 클릭 → 상품 상세페이지 이동
7. 좌우 화살표 버튼 클릭 시에도 동일 스냅+오버레이 로직 적용

## 3. 수락 기준
- [ ] AC-1: 정확히 7개 슬롯 (부족하면 판매량 순으로 채움)
- [ ] AC-2: 스와이프 종료 시 항상 타일 중앙 정렬로 스냅
- [ ] AC-3: 스냅 애니메이션 중에는 오버레이 숨김, 완료 후에만 표시
- [ ] AC-4: 상세보기 클릭과 이미지 클릭 모두 상세페이지로 이동
- [ ] AC-5: 관리자가 특정 상품을 TOP7에 강제 고정 가능
- [ ] AC-6: 모바일/데스크톱 모두 정상 표시

# T04 — 재단 옵션 (확정 스펙)

## 1. 목표
- 600×600 상품에 한해, 상세페이지 주문정보에서 600×300 재단 옵션 선택 가능. 선택 시 +20% 가격 적용 (박스 수는 동일하게 유지)

## 2. Step-by-step
1. 상품 데이터에 `cuttable: boolean` 필드 추가 — 600×600 상품만 true
2. 상세페이지 주문정보 박스 안에 재단 옵션 토글/셀렉트 UI 추가 (cuttable=true인 상품에만 노출)
3. 선택 시: 표시 사이즈를 "600×300 (재단)"으로 변경, 단가에 ×1.2 적용, 박스 수는 그대로
4. 타일 계산기 합계에 +20% 반영
5. 장바구니/주문 데이터에 재단 여부 및 최종가 저장

## 3. 수락 기준
- [ ] AC-1: 600×600 상품에만 재단 옵션 노출, 다른 사이즈엔 없음
- [ ] AC-2: 옵션 선택 시 가격 정확히 +20%, 박스 수 불변
- [ ] AC-3: 장바구니/주문내역에 재단 여부 표시
